# Lemo-Opuscar films

The 720p demo films of the 99 styles in [Lemo-Opuscar](https://github.com/sunqinji666-dotcom/lemo-opuscar), one per style, named after the style folder (`<slug>.mp4` for `styles/<slug>/`). GitHub Pages serves them at `https://sunqinji666-dotcom.github.io/lemo-opuscar-films/<slug>.mp4` for the gallery, https://sunqinji666-dotcom.github.io/lemo-opuscar/

They are made in the main repository and copied here by its `tools/films_repo.sh`: change them there, not here. The films at full quality are on the main repository [films release](https://github.com/sunqinji666-dotcom/lemo-opuscar/releases/tag/films); each film sources and credits are in `styles/<slug>/demo/CREDITS` there.
